# glrs.dev

The documentation site is generated by [TypeDoc](https://typedoc.org/).

- API reference is grouped as Core, Coding Agent, and Providers using explicit entry points and TypeDoc's `structure-dir` router.
- Long-form guides use TypeDoc External Documents rooted at `docs/published/index.md`.
- `theme/index.ts` registers the custom `glrs` theme.
- `theme/glrs.css` carries the glrs.dev visual system.
- `@boneskull/typedoc-plugin-mermaid` renders Mermaid diagrams with a local pinned Mermaid bundle.

```sh
cd docs-site
bun install
bun run build
bun run dev
```

The local server runs at `http://127.0.0.1:4180/`. `bun run dev` watches External Documents, API entry points, TypeDoc configuration, theme files, and public assets; successful rebuilds reload connected browsers automatically.
