# Install

<PackageSwitcher />

## Recommended

```sh
curl -fsSL https://glrs.dev/install.sh | bash
```

## Manual

Requires [Bun](https://bun.sh) ≥ 1.2 and git.

```sh
bun add --global @glrs-dev/glorious@next
```

<PackageInstall />

## First run

```sh
export AZURE_OPENAI_API_KEY=…
export AZURE_RESOURCE_NAME=…
glorious
```

Continue with the [quickstart](/quickstart).
